> DLC 2 스토리 스포일러 있음.

## 꿀팁 요약

- **들어가기 전 필수 준비**: 봉래의 옥의 가지(또는 월병) 6개 + 귀살주 6개. 이게 3페이즈 클리어 키
- 조리 도구는 **제일 빠른 도구 5세트**. 밤참새 도구 같은 만족도 보정은 다 무효라 의미 없음
- 1페이즈: 2레벨짜리 **싼 요리 아무거나 계속 던지기**. 처벌 카드 없음
- 2페이즈: 희귀 손님 표 옆에 켜두고 **4점(빨강)만 노리기**. 필수 태그가 손님 불호면 바뀔 때까지 대기
- 3페이즈: 스턴 걸린 코이시에게 **봉래의 옥의 가지 + 귀살주 = 9점**. 4번 → 다시 스턴 → 2번 = 54점 클리어

**참가 조건**: 옛 지옥·지령전 손님 6명 인연 최대 → 오린 통해 참가.

## 1페이즈 — 가려진 주문 20명

- 일반 손님 주문이 전부 가려짐. 메뉴 상관없이 **손님 선호 태그만 보고** 던지면 됨
- 3점 이상이면 만족, 20명 채우면 끝
- 처벌 카드가 없어서 하나하나 맞추는 것보다 **아무거나 빨리 던지는 게 더 빠름**

## 2페이즈 — 희귀 손님 10명 (제일 어려움)

하나라도 어기면 바로 처벌 카드.

- 30초마다 바뀌는 **필수 태그**가 요리에 있어야 함
- 요리에 **추가 재료 필수**
- **불호 태그 하나라도** 있으면 실패
- 요리 + 음료 합계 **4점(빨강)** 필수. 3점(주황)도 실패

꿀팁:
- [희귀 손님 전체표](/customers/rare/) 옆에 띄워두고 하면 체감 난이도 확 내려감
- 쫓아내기 불가. 필수 태그가 그 손님 불호면 **태그 바뀔 때까지 기다리는 게 정답**
- 이상함·기름짐·날 것처럼 싫어하는 손님 많은 태그가 떴는데 곧 바뀔 타이밍이면 무리하지 말기

## 3페이즈 — 코이시

| 단계 | 할 일 |
|---|---|
| 1 | 2번 테이블 코이시 **본체** 주문은 완전히 가려짐 |
| 2 | 나머지 테이블 **분신**이 무작위 요리·술 주문. 요구 요리 + 필수 태그로 4점 띄우면 본체의 **선호 4 / 불호 2 / 술 1** 공개 |
| 3 | 공개된 태그 맞춰 본체에게 요리·술 → 본체 **스턴** |
| 4 | 스턴 중엔 제약 없이 먹일 수 있음. 점수 = 요리 레벨 + 술 레벨 |

**54점 클리어 루트**
1. 분신 처리해서 태그 공개 → 본체 스턴
2. 봉래의 옥의 가지 + 귀살주 4번 (36점) → 코이시가 마음 닫고 태그 전부 리셋
3. 분신 다시 처리 → 다시 스턴
4. 봉래의 옥의 가지 + 귀살주 2번 (18점) → **총 54점 클리어**

추가 꿀팁:
- 공개된 태그 4개가 딱 맞는 요리는 도감에 최소 하나 있음. 태그 다 안 열려도 추리 가능
- 분신 상대하다 보면 시간 빠듯함 → **던지기 버프로 시간 멈추는 거 꼭 유지**
