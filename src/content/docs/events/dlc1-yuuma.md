> DLC 1 스토리 스포일러가 있어요.

## 배경

본편 이변의 원인인 "탐욕의 과실"을 쫓다 보면, 니토리가 과실로 달래려던 끝없이 배고픈 **토테츠 유마**를 미스티아가 직접 배불리 먹이러 피연못지옥에 가게 돼요.

## 규칙

| 항목 | 내용 |
|---|---|
| 목표 | 유마(와 분신)를 계속 먹여 게이지를 끝까지 채우기 |
| 제시 태그 | 무작위 태그 2개. **요리에 반드시 포함**해야 해요. 게이지 10%마다 바뀌어요 |
| 광폭화 게이지 | **음료 도수에 비례해서** 차요. 가득 차면 요리·음료·재료 여럿과 **조리 도구 하나를 그 라운드 동안 빼앗겨요** |
| 인내심 프리즈 | 안 통해요 |
| 후반 | 태그 대신 특정 요리·음료를 직접 요구하는 경우가 많아져요 |

## 요령

1. **음료 도수가 승부예요.** 초반 태그 주문에는 되도록 무알콜·도수 낮음 음료를 주세요.
2. 도수 높음 음료를 대놓고 요구하는 주문은 **최대한 뒤로 미루고**, 도수 낮은 음료를 요구하는 주문부터 처리하세요.
3. 요구한 요리가 재료가 많아 제시 태그를 못 맞추면, 다른 분신을 먼저 먹여서 태그를 바꾸세요.
4. 제시 태그 2개를 동시에 맞추기 쉬운 요리를 미리 찾아 두면 편해요. [요리 레시피 전체](/dishes/)에서 태그 두 개로 걸러 보세요.
