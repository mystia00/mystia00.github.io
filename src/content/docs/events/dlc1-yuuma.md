> DLC 1 스토리 스포일러 있음.

## 꿀팁 요약

- **광폭화 게이지는 술 도수로만 참.** 무알콜·도수 낮음 위주로 주면 광폭화 거의 안 봄
- 도수 높음 술 요구하는 주문은 **최대한 뒤로 미루고** 도수 낮은 주문부터 처리
- 제시 태그 2개를 동시에 만족하는 요리를 **미리 몇 개 찾아두기**. [요리 레시피 전체](/dishes/)에서 태그로 거르면 금방 찾음
- 요구 요리가 재료 많아서 제시 태그를 못 맞추면 **다른 분신부터 먹여서 태그 갈아치우기**

## 규칙

| 항목 | 내용 |
|---|---|
| 목표 | 유마와 분신을 계속 먹여서 게이지 끝까지 채우기 |
| 제시 태그 | 무작위 2개. 요리에 **반드시** 포함. 게이지 10%마다 교체 |
| 광폭화 | 술 도수에 비례해서 참. 가득 차면 요리·음료·재료 여럿 + **조리 도구 하나를 그 라운드 동안 뺏김** |
| 인내심 프리즈 | 안 통함 |
| 후반 | 태그 대신 특정 요리·술을 직접 요구하는 비율 증가 |

## 진행 순서

1. 초반: 태그 주문에는 무알콜·도수 낮음 술로 응대
2. 제시 태그 바뀔 때마다 미리 찾아둔 요리로 빠르게 처리
3. 후반 특정 요리 요구: 바로 만들 수 있는 것부터, 재료 많은 건 뒤로
4. 도수 높음 요구는 게이지 여유 있을 때 몰아서 처리
