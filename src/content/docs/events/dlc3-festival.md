> DLC 3 스토리 스포일러 있음.

## 꿀팁 요약

- **우리 편은 코스즈 고정.** 콤보당 조리 시간 1% 감소라 콤보 10~20만 쌓아도 상대보다 늦게 시작해도 먼저 완성해서 손님 뺏음
- **콤보만 안 끊기면 누구든 압살.** 콤보 끊는 실수가 유일한 패배 원인
- 아운은 원거리 서빙이 없어서 최약. 쓴다면 **토지코전 버림패**로 (석상이라 번개 면역)
- 2승 하면 3라운드 제안 나오는데 승패와 무관. 해도 되고 안 해도 됨

**참가 조건**: 명련사·신령묘 전원 인연 5레벨 → 마미조와 대화. 신령묘 요리대회 / 명련사 음악대회 중 선택 (이 페이지는 요리대회).

## 규칙

- 신령묘 3명 vs 우리 3명, **1:1 대결 3판 2선승**
- 평소처럼 영업하는데 **손님을 상대와 공유**. 영업 끝났을 때 점수 높은 쪽 승리
- 재료·음료 100개씩 지급, 메뉴는 명련사·신령묘 인연 요리 고정

## 우리 편

| 캐릭터 | 능력 | 평가 |
|---|---|---|
| 모토오리 코스즈 | 보통 이상 평가마다 분위기 +15, 콤보당 조리 시간 1% 감소, 원거리 서빙 | **최강. 고정 픽** |
| 미스티아 | 도철의 만찬, 원거리 서빙, 인내심 프리즈 | 평소랑 같음. 무난 |
| 코마노 아운 | 팁 +15%, 서빙한 손님에게 계속 팁 (피버 때 2배), 인내심 프리즈 | 원거리 서빙 없어서 최약. 번개 면역 |

## 상대별 카운터

| 상대 | 방해 기술 | 카운터 |
|---|---|---|
| 곽청아 | 30초마다 테이블 3개 20초 봉쇄, 벽 통과, 중식 즉시 완성 | **최약체.** 이동 느림. 봉쇄 안 걸린 테이블 먼저 처리하다가 풀리는 순간 던지기. 아운으로도 이김 |
| 소가노 토지코 | 10초마다 내 위치에 번개 (맞으면 10초 기절, 빗나갈수록 최대 4발), 50% 확률 순간이동, 냄비 즉시 완성 | 바닥 경고 뜨면 바로 피하기. 주방에도 떨어지니 조리 중에도 주의. 순간이동 때문에 원거리 서빙 없으면 손님 다 뺏김 |
| 모노노베노 후토 | 20초마다 3곳에 불 (닿으면 5초 둔화 + 방향키 반전), 도마 즉시 완성, 요리·술 던짐 | 불 장판 피해서 이동. 던지기가 있어서 빠름 → 콤보 유지로 조리 속도 이기기 |
